## Abstract

We study the recovery of directed acyclic graphs (DAGs) from observations
generated by a linear structural equation model. DAG structure learning is
challenging because acyclicity is a global combinatorial property, and continuous
formulations generally involve difficult optimization landscapes. By restricting
edge weights to be non-negative, we obtain a simpler, smooth log-determinant
characterization of acyclicity that avoids Hadamard products. Building on this
characterization, we introduce NOMAD, a non-negative DAG estimator based on the
method of multipliers, with Adam and FISTA implementations for its inner
optimization. The resulting learning problem remains non-convex. Under the
population assumptions and parameter conditions stated in the paper, the true
DAG is the unique global minimizer of the population augmented Lagrangian, there
are no spurious interior stationary points, and the true DAG is the only acyclic
KKT point. We also establish local convergence of the analyzed projected-gradient
scheme under suitable conditions. Experiments on synthetic data and the Sachs
protein-signaling benchmark evaluate estimation accuracy and structural recovery
against established DAG-learning baselines.

NOMAD is implemented as `MetMulDagma` in [src/model.py](src/model.py).
The baselines include DAGMA, NonDAGMA, CoLiDE-EV/NV, NOTEARS, NoFears,
GOLEM-EV/NV, and SortNRegress. A DAGuerreotype wrapper is also available for
additional comparisons. The experiments under `nonneg_colide/` are separate from
the main TSP evaluation.

### Running the experiments

After installing and activating the environment described in
[Quick start](#quick-start), run these commands from the repository root:

```bash
# Table I: nominal ER setting only
SCENARIOS=er4_N100_var1 python synthetic/scripts/preliminary_exp.py

# Figure 1 and additional noise experiments
python synthetic/scripts/number_samples.py
python synthetic/scripts/different_vars.py
python synthetic/scripts/graph_size.py
python synthetic/scripts/noise_types.py

# Open the Sachs experiment and analysis notebooks
jupyter notebook
```

The `SCENARIOS=...` syntax above is for Bash. In PowerShell, set
`$env:SCENARIOS = 'er4_N100_var1'` before running the Python command.
Without this filter, `preliminary_exp.py` runs additional synthetic scenarios.
Set `N_CPUS` to control the number of Joblib workers. Experiment parameters and
the `LOAD`/`SAVE` controls are defined in the scripts or notebook setup cells.

Open notebooks with a working directory inside this repository and select the
`cvx_dag_learning (.venv-dag)` kernel. Their initial setup cell locates the project
root. Analysis notebooks default to loading saved results; set `LOAD=False` to
rerun their experiments. Full synthetic sweeps, especially the large-graph
experiments, can take substantially longer than the minimal example below.

The Sachs input files are included in [datasets/sachs/](datasets/sachs/).
[get_sachs_data.ipynb](real/sachs/notebooks/get_sachs_data.ipynb) regenerates the
NumPy inputs from the included text data. The main experiment uses 853
observations, 11 variables, and the reference graph with 17 directed edges.
For Table II, use the results before the notebook's rescaling analysis. The paper
selects `NOMAD-adam`, `DAGMA-std`, `NonDAGMA`, `CoLiDE-EV`, `CoLiDE-NV`,
`GOLEM-EV-std`, `GOLEM-NV-std`, and `SortNReg`. The following graph-export cell
generates the PDFs for Figure 2.

### Reproduction status

The experiment entry points are available, but exact reproduction of every
reported number from a fresh clone is still being reconciled:

- The main reference results are local files ignored by Git. Existing result
  archives use `preliminary_erdos/`, `samples_erdos/`, `var_erdos/`, and
  `size_euler/` under `results/`, whereas the current scripts use the output
  directories listed above. Loading these archives requires adjusting the
  corresponding result path.
- The nominal CSVs currently available do not exactly match Table I. Its runner
  also needs to retain TPR and FDR to export all table columns.
- Figure 1(a) uses the `GOLEM-EV-Fix` variant, currently commented out in the
  sample-size runner, and mean/standard-deviation error CSVs that its current
  export function does not generate. The graph-size runner also differs from
  the iteration settings saved with the Figure 1(c) results.
- `src/utils.py::compute_norm_sq_err` compares individually normalized matrices;
  this differs from the normalized squared Frobenius error defined in the
  manuscript. The metric definition and reported results need to be aligned.
- Synthetic runners use global random seeds rather than explicit seeds per
  parallel task. Thresholds and preprocessing also vary: synthetic sweeps use
  an evaluation threshold of 0.2, the nominal comparison uses 0.3, and Sachs
  applies standardization and thresholds of 0.1 or 0.3 according to the method.

These details must be aligned with the final manuscript and reference outputs
before claiming exact numerical reproducibility. The existing Sachs notebook
outputs match Table II, and the local CSV/PDF inputs to Figures 1 and 2 have
been traced to saved experiment outputs.

## Quick start

### Installation

The experiment setup targets **Python 3.10 on Linux**; Windows users can use
WSL. From the repository root, create and activate the environment:

```bash
bash scripts/create_repro_env.sh
source .venv-dag/bin/activate
```

The installer uses `requirements-repro.txt` and registers the notebook kernel.
It also builds the optional DAGuerreotype implementation and its `lp-sparsemap`
dependency, requiring `git`, `g++`, `make`, `curl`, `unzip`, and Python 3.10
development headers. See [ENVIRONMENT.md](ENVIRONMENT.md) for build details and
configuration options. The earlier `requirements.txt` does not include all
dependencies needed by the current experiments.

### Minimal example

Run the following code from the repository root in Python or a notebook. It
generates a small synthetic dataset and fits NOMAD with Adam:

```python
import random

import numpy as np

from src.model import MetMulDagma
from src.utils import simulate_sem

random.seed(10)
np.random.seed(10)

W_true, _, X = simulate_sem(
    n_nodes=10,
    n_samples=500,
    graph_type="er",
    edges=20,
    edge_type="positive",
    w_range=(0.5, 1.0),
    var=1.0,
)

model = MetMulDagma(primal_opt="adam", acyclicity="logdet")
model.fit(
    X,
    lamb=0.2 * np.sqrt(np.log(X.shape[1]) / X.shape[0]),
    stepsize=5e-3,
    alpha_0=0.1,
    rho_0=0.1,
    s=1.0,
    iters_in=5000,
    iters_out=10,
    beta=1.5,
)

W_est = model.W_est
print("Estimated adjacency shape:", W_est.shape)
print("Edges with weight >= 0.3:", np.count_nonzero(W_est >= 0.3))
```

Rows of `X` are observations and columns are variables. `W_est[i, j]` represents
the estimated weight of the edge from variable `i` to variable `j`. The model
centers the observations by default. This example illustrates the API; the
paper experiment settings are defined in the entry points listed above.
